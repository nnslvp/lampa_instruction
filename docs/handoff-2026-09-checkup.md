## 3. Что проверить (по шагам)

1. **Метрика** (MCP): достижения `blancvpn_click` за последние 30 дней vs 44;
   разрез по параметрам цели (отчёт params: `ym:s:paramsLevel1/2`) — какие `page`
   и какие `pos` приносят клики; просмотры 6 новых URL (`ym:pv:URLPath`); отказы
   по новым страницам; общий тренд визитов vs 7 879.
2. **GSC** (Chrome): Индексирование → Страницы — сколько проиндексировано (главный
   вопрос месяца: сдвинулось ли с нуля); Эффективность — есть ли показы/клики из
   Google; статус sitemap. Непроиндексированным важным URL — повторно Request indexing.
3. **Вебмастер** (Chrome): Эффективность → Статистика — динамика показов/кликов/позиции
   vs база; появились ли показы у 6 новых страниц (разрез «URL»); позиции целевых
   кластеров: «torrserver для lampa» (была 6,7), «плагины для lampa 2026» (была 4,1),
   «настройка lampa» (была ~4,7), «lampa» (была 8,7), cub-кластер (была ~7,9).
4. **Кабинет BlancVPN** (Chrome, владелец вводит код входа): Total clicks / leads /
   customers / earnings vs база из раздела 2; Reports за месяц.
5. **Плагины**: `./check_plugins.sh` — новые мёртвые? Правило: **страницы плагинов
   никогда не удалять** — только `status: "Не работает"`, `status_icon: "❌"`,
   альтернатива в описании (образец: `_plugins/videocdn.html`); сначала искать новый
   URL плагина (пример: shikimori переехал в `Shikimori/Shikimori.js`).

## 5. Отложенное решение: перенос CTA на карточках плагинов

К моменту запуска этого хендоффа baseline по `pos` накоплен (>14 дней с 17.08).
Правило из спеки:

- Посмотреть в Метрике разрез кликов по `pos` для страниц с `page` = `plugins-*`
  (сейчас на карточках только pos=top — верхний geo-блок).
- Реализовать перенос: в `_layouts/plugin.html` убрать верхний geo-warning, сразу
  ПОСЛЕ steps-container вставить `{% include vpn_block.html … pos="mid" %}`
  (заголовок — про момент установки, 4 варианта текста по `длина slug mod 4`).
  Одним коммитом (иначе check_cta.rb в CI упадёт). Отдельный MR.
- **Критерий отката**: если за 14 дней после переноса конверсия визит→blancvpn_click
  по карточкам ниже baseline-периода — revert коммита, верхний блок возвращается.

## 6. Ориентиры успеха (не жёсткие KPI, а сигналы)

- Клики по партнёрке: **≥60–70/30д** — план работает; <50 — разбираться в разрезе page/pos.
- Google: **≥20 проиндексированных страниц** — разблокировано; всё ещё 0 — проверить
  Cloudflare (не режет ли Googlebot) и сообщить владельцу, это станет главной проблемой.
- Новые страницы: ненулевые показы в Вебмастере у ≥4 из 6 — нормально для первого месяца.
- Кабинет: любые новые лиды/покупатели — бонус; главная метрика месяца — клики и индексация.
